# v0.4.0

这一版有**用户能看到的变化**：新增「置顶悬浮」，进度方格改进，还修了一个带金模式下的显示 bug。

---

## 新功能：置顶悬浮（给不直播的人用）

如果你不直播、只想自己看着玩 —— 现在可以点右下角的「**置顶悬浮**」按钮：

- 覆盖层会放进一个**始终置顶**的小窗口，可以**拖动**、可以**缩放**
- 同时还能正常看游戏、看别的窗口，不用来回切
- 窗口里按钮变成「**还原**」，点一下回到浏览器页面

**窗口变小时卡片会自动缩放**，拖成刚好包住卡片的大小就行。

> 按钮平时是**隐藏的**，鼠标移到页面上才浮出来 —— 直播时观众看不到它。
>
> 需要 **Chrome / Edge 116 或更高版本**。不支持的环境（比如 OBS 的浏览器源、
> QQ 浏览器的极速内核）里按钮不会出现，或者会提示换浏览器。

## 进度方格的改进

**小节多的时候不再挤在一起**

以前小节一多（比如 9 个）就全部铺开，字号被压到 12px、方格看不清。
现在离当前小节越远的会**越小越淡**（逐渐淡出），把视觉重心留给当前位置。

**已通过的小节标绿**

一眼能看出打到哪了。（以前这个绿色被另一条样式规则盖掉了，一直没显示出来。）

**方格不再被压成小圆点**

当前小节的列宽以前会被挤到 40px，方格算出来只有 8px，配上圆角看起来像小圆点。
现在给了硬性下限，方格是 14×14 的方块。

**最右侧的百分比占位缩小**

以前固定 106px（按「100.0%」的宽度留的），「6.7%」这种短数字看起来空一大块。
现在缩到 96px、字号 28→24px。

## 修了一个 bug

**带金的时候第三张卡片没变金**

「攻下一个小节时的绿光」和「镀金扫光」用的是同一个图层，绿光那条样式把它盖掉了 ——
而且攻下过一个小节之后就一直盖着。现在两个效果能正确区分。

## 内部重构（来自 PR [#5](https://github.com/L-FLA5H/MapClearingStats/pull/5)、[#6](https://github.com/L-FLA5H/MapClearingStats/pull/6) - [@glcoge](https://github.com/glcoge)）

**没有任何画面变化**，都是代码整理：

- **CCT 数据格式知识收敛到 `CctClient` 分区**（PR #5）——
  以后 CCT 改了字段名，只用改一个地方
- **一命模式三态化**（PR #6）—— 原来用「布尔 + 类型缓存」两个变量共同表达
  「初见 / 带金 / 带银」三种状态，现在收成一个三态变量，判断统一走一张配置表
- 新增两个自检脚本：`tools/check-cctclient.js`、`tools/check-goldenmode.js`

## 安装

**覆盖层的装法和之前完全一样** —— 下载 `ExternalOverlay.zip`，
把整个文件夹覆盖到：

```
<Celeste 安装目录>\ConsistencyTracker\external-tools\ExternalOverlay\
```

> ⚠️ 更新之后要在覆盖层窗口里按 `Ctrl + R`，否则跑的还是旧代码。

**LevelWatcher 这一版没有改动**，不用重装。

## 已知限制

- 只显示**当前章节**的数据（CCT 的接口范围）
- 房间进度方格需要**提前录制过一次路径**
- 「置顶悬浮」需要 Chrome / Edge 116+；悬浮窗口的标题栏是浏览器画的，去不掉
