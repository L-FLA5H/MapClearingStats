# v0.3.0

新增了**带金 / 带银（一命挑战）模式** —— 拿起金草莓或银草莓时，
整块面板会「镀」成金色 / 银色，并切换成只显示**这一命**的数据。

## 新增

### 一命挑战模式

拿起金草莓 / 银草莓时自动进入：

- **镀色动画** —— 金色 / 银色从卡片**左边缘往右**扫上来，像镀一层；
  死亡退出时**往右扫走**并渐隐，不会在左边缘留下残影
- **徽章** —— 右上角出现「带金」/「带银」标识
- **带金成功率** —— `通过数 / 进入数`，例如 `18.18%（2/11）`
- **进入率** —— 从开头带到当前面的几率
- **带金死亡** —— 本章累计 + 本次会话
- **本面近 20 次通过情况走势条** —— 20 个方块：绿=通过、红=失败、空心=还没记录；
  左端「较早」、右端「近期」
- **连续通过 / 最高连续通过**

### 模糊层重做

原来逐张卡片加 `blur`，三张卡片的动画时序各不相同，导致只有第三张真的糊了。
改成**一块统一的遮罩盖住整个面板**，并且边缘做了羽化（不再是硬方框边）。

## 修复大坨bug

- **本面死亡数不实时** —— 「没变化就跳过重绘」的提前返回把它挡掉了
- **重开章节后死亡数残留** —— 重开时清了数据，但 CCT 那边的计数还是旧值，
  又被当成「新的一次死亡」加了回去；现在重开后第一次检测只记基准、不计数
- **带银显示成带金** —— 金银映射反了（实测 `0 = 金`、`1 = 银`）
- **进入率字段用错** —— 用成了「卡关率」，正确的字段是「带金进入几率」
- **「带金局数」拿不到** —— 该字段 CCT 只在特定时刻提供，拿不到时退回显示「带金死亡」
- **第二张卡片空白** —— 走势条没数据时整行被隐藏
- **银卡退场变金** —— 退出时图层会瞬间回落到默认的金色，现在动画期间锁住银色
- **走势条不刷新** —— CCT 的「暂停死亡追踪」被设为了开启（见下方设置说明）
- **方格只有进入动画没有退出动画** —— 改成复用节点，颜色变化走过渡
- **跨天丢数据** —— 存档从 `sessionStorage` 换成 `localStorage`，并加了
  「关窗口时存一次 + 每 12 秒存一次」两道保险
- **切换动画被取消**、**镀色方向反了**、**卡片高度跳变** 等一批动画问题

## 动画

- **镀色扫光** —— 金色 / 银色从卡片左边缘往右扫上来；死亡退出时往右扫走并渐隐
- **成功率的数值缓动** —— 数字平滑滚动到新值（先快后慢），和本面死亡 / 本面用时一致
- **进入率 / 局数** —— 保留「弹跳」动画（放大 + 提亮）
- **走势方格** —— 变化时从右往左依次过渡，读起来像「新的一次尝试从右边推进来」


## 安装

和之前相同，覆盖层的三个文件覆盖过去即可。

| 文件 | 用途 |
| --- | --- |
| `LevelWatcher.zip` | 辅助 Mod，解压后放进蔚蓝的 `Mods` 文件夹 |
| `MapClearingStats-Overlay-v0.3.0.zip` | 覆盖层页面，解压后覆盖到 CCT 的覆盖层目录 |

1. 安装 [Everest](https://github.com/EverestAPI/Everest) 与 [ConsistencyTracker](https://github.com/viddie/ConsistencyTrackerMod)
2. 下载 `LevelWatcher.zip`，解压到蔚蓝的 `Mods` 文件夹
3. 下载 `MapClearingStats-Overlay-v0.3.0.zip`，把里面的 `ExternalOverlay` 三个文件覆盖到
   `ConsistencyTracker/external-tools/ExternalOverlay/`（**覆盖前建议先备份** CCT 自带文件）
4. 在 CCT 设置里给要直播的地图录一次路径
5. OBS 添加「浏览器」来源，选本地文件 `CCTOverlay.html`，宽 620 高 400

### ⚠️ 两个设置注意

1. **走势条想实时刷新的话**，要把 CCT 的 `暂停死亡追踪`（Pause Death Tracking）设为 **关**。
   开着的时候 CCT 不记录房间尝试，走势条就不会更新。
2. **更新文件后要在覆盖层窗口里按 `Ctrl + R`** —— 浏览器页面不会自动加载新代码。

## 依赖

- Celeste + Everest 1.5935.0+
- [ConsistencyTracker](https://github.com/viddie/ConsistencyTrackerMod)（必装，数据来源）

本仓库不包含任何第三方 Mod 的代码。

## 已知限制

- 方格进度依赖 CCT 的路径录制，没录过路径的地图只会显示提示文字
- 「局数」这个数据 CCT 只在拿着金草莓的那一刻短暂提供，没拿时是空的 ——
  覆盖层在拿不到时会退回显示「带金死亡」
- 覆盖层是浏览器页面，**更新文件后必须按 `Ctrl + R` 重新加载**才会生效
